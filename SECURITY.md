# Security Policy

## Supported Versions

| Version | Supported  |
| ------- | ---------- |
| 1.4.x   | ✅          |
| 1.3.x   | ⚠️ Limited |
| 1.2.x   | ❌          |
| Older   | ❌          |

---

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue immediately.

Instead:

1. Contact the maintainer privately.
2. Include a detailed description of the issue.
3. Include reproduction steps if possible.
4. Include screenshots or logs if relevant.

Security reports will be reviewed as quickly as possible.

---

## Security Goals

This project aims to:

* Avoid telemetry and unnecessary data collection.
* Store logs locally only.
* Never transmit personal information.
* Minimize required permissions.
* Keep external dependencies transparent.

---

## Scope

Examples of issues that may qualify:

* Remote code execution vulnerabilities
* Privilege escalation
* Exposure of sensitive information
* Malicious dependency injection
* Unsafe command execution

Examples that generally do not qualify:

* Cosmetic UI issues
* Installer delays
* Minor usability bugs
* Third-party service outages
