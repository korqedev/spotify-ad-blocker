# Changelog

## [1.4.0] - 2026-06-18

* Animated progress bar
* Live runtime counter
* Installation summary page
* Startup animation sequence
* Loading spinner animation
* Error code system
* Automatic log viewer on failure
* Version tracking

### Improved

* Cleaner installer interface
* Better status reporting
* More professional installation flow

* Removed external webhook telemetry
* Switched to local-only logging
